## 🎯 Objetivo

Centralizar e organizar comandos úteis para consulta rápida, ajudando desenvolvedores a serem mais produtivos.

## 📖 Como usar

1. Navegue pela pasta da tecnologia desejada
2. Escolha o arquivo com o nível de complexidade:
   - `comandos-basicos.md` - Para iniciantes
   - `comandos-avancados.md` - Para usuários experientes
   - `boas-praticas.md` - Dicas e recomendações

## 🤝 Como contribuir

1. Faça um fork do projeto
2. Crie uma branch: `git checkout -b minha-contribuicao`
3. Adicione seus comandos seguindo o formato descrito em [Formato dos comandos](#formato-dos-comandos)
4. Commit: `git commit -m 'Adiciona comandos XYZ'`
5. Push: `git push origin minha-contribuicao`
6. Abra um Pull Request

## 📝 Formato dos comandos

Cada comando deve ser documentado com:

```markdown
### `comando`
````

**Descrição:** O que faz

**Uso básico:**

```bash
comando [opcoes] [argumentos]
````
